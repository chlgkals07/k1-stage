## 이 기록에서 되풀이해 나온 것

- **관리본을 믿지 말고 로봇에 물어본다.** `k1_config.yaml`의 모드 목록이 실배포보다
  뒤처져 있어 실행이 조용히 거부됐다. `tools/check_modes.sh`와
  [reference/ROBOT_MODES_20260812.md](../reference/ROBOT_MODES_20260812.md)가 그 대응이다.
- **배포 누락이 두 번 사고를 냈다.** 로봇 실행본이 컨테이너 안에 있어 PC에서 고쳐도
  반영되지 않았다. `run.sh`의 md5 대조가 그 대응이다.
- **주소 충돌은 설정으로 못 피한다.** ASUS 공유기 기본값과 겹친 `192.168.50.1` 문제는
  구조적이라 대역을 옮겨야 했다 ([RUNBOOK §1](../RUNBOOK.md#1-장소-준비--새-장소일-때만)).
