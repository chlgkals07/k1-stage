# 데모 영상용 추천 다이얼로그 (2026-08-13)

> **음성 대화용 데모 시나리오다. 그 기능은 2026-08-18에 제거됐다** —
> [STATUS.md §8](../STATUS.md#8-음성-대화-2026-08-18-제거).
> 4막 구성과 동작 배치는 지금의 패드·무대 시연 순서를 짤 때도 그대로 쓸 수 있다.

카메라 앞에서 그대로 따라 하는 시나리오다. LLM 개방 21개 기준.
**진행 원칙**: 동작이 끝나고 로봇이 준비 자세로 돌아온 뒤 다음 발화. 위험 동작 전에 공간 확보 멘트를 카메라에 담으면 안전 운영도 함께 보여줄 수 있다.

## 1막 — 만남 (제자리, 안전)

| 발화 | 기대 반응 |
|---|---|
| "안녕, 케이원!" | 손 흔들기 + 짧은 인사 |
| "만나서 반가워" | 캐주얼 인사 |
| "네 소개 좀 해줄래?" | **말로만** 자기소개 (동작 없음 — 지능 보여주는 컷) |
| "지금 몇 시야?" | 시간 확인 시늉 + 음성 답변 |

## 2막 — 상호작용

| 발화 | 기대 반응 |
|---|---|
| "이리 와봐" | 이리 오세요 손짓 |
| "우와, 대단하다!" | 큰 박수(환호) |
| "완벽했어" | 손키스 |
| "잠깐 진정해봐" | 진정하세요 |
| "같이 놀자" | 안세카반세 |

## 3막 — 퍼포먼스 (명시 요청 전용 3종, 클라이맥스)

> 여기부터 공간 확보. "다들 뒤로 물러나 주세요" 멘트를 영상에 포함 권장.

| 발화 | 기대 반응 | 비고 |
|---|---|---|
| "체스트팝 보여줘!" | 체스트팝 | cooldown 8초 |
| "재즈핸즈 춰줘!" | 재즈핸즈 | 정확히 지목해야 나옴 (cd 10초) |
| "팔굽혀펴기 해봐!" | 팔굽혀펴기 | 엎드림 — 바닥 공간 (cd 15초) |
| **"옆돌기 해줘!"** | **카트휠** | **최대 공간 + E-stop 대기. 피날레** (cd 20초) |

게이팅 확인 컷(선택): "신난다~ 흥이 나네!" → 재즈핸즈가 **안** 나오고 말로만 호응하면, "지목했을 때만 춘다"는 통제력을 보여주는 장면이 된다.

## 4막 — 작별

| 발화 | 기대 반응 |
|---|---|
| "오늘 고마웠어" | 배꼽 인사 or 정중한 박수 |
| "잘 가, 다음에 봐!" | 배웅 인사 |

## 안전 컷 (영상 신뢰도용, 선택)

- "복싱 해봐" → 거부 + "그건 할 수 없어요" (섀도우복싱은 어느 경로도 안 열림)
- 동작 중 `/operator` 빨간 정지 버튼 → 즉시 준비 자세 복귀

## 촬영 팁

- 말-동작 싱크가 이번 개선 포인트 — 발화 직후 팔이 움직이는 순간을 측면에서
- 실패 컷도 로그에 남는다 (`logs/*.jsonl`) — 재촬영 전에 desc 튜닝 가능

# 다시 시작하는 방법

```bash
# 0. (한 번만) PC 에서 OpenAI key 채우기 — 비어 있으면 음성이 안 된다
nano ~/.k1/secrets.env        # OPENAI_API_KEY=sk-... 채워넣기

# 2. PC 에서 — 죽은 gateway 도 자동으로 올려준다. 파일 동기화까지 --deploy 로
pkill -f "server.py --relay" 2>/dev/null
cd /home/robotis-ai/Projects/shape3/k1-stage/solo_stage
./run.sh --deploy

# 3. 확인
tools/check_modes.sh          # 42개 로드 + allowlist 대조
# 폰: 북마크 URL 접속 → SD OFF→ON → 3초 → /operator 'API 준비됨'
```

체크: relay 터미널에 `세션 로그 logs/....jsonl` 줄이 보여야 기록이 남는다.
