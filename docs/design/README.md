# 디자인 참고 자료

`shape-design/` 은 동아리 공식 디자인 킷의 **사본**이다. 원본은 동아리 사이트
저장소 `shape_new_web` 의 `design-system/` 이고, 배포본은 사이트의
바로가기 → SHAPE 자료에서 zip 으로 받는다. 여기 둔 이유는 시안이 바뀌었을 때
**어느 판을 보고 무대 화면을 만들었는지가 남아야** 하기 때문이다.

- 받은 날: 2026-09-20 (Pretendard 1.3.9 기준)
- 이 킷으로 만든 테마: `web/themes/shape-site/`

값을 고칠 일이 있으면 여기가 아니라 원본을 고치고 zip 을 다시 떠서 이 폴더를
통째로 갈아 끼운다. `tokens/tokens.css` · `kit/shape-kit.css` · `kit/token-names.js`
는 생성물이라 손으로 고쳐도 다음 빌드에 지워진다.

읽을 순서는 `shape-design/AGENTS.md` → `foundations/` → `components/` 다.
