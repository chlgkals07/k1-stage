# 포스터·전단·카드를 만들 때 쓰는 프롬프트

주는 파일: `AGENTS.md`, `kit/shape-kit.css`, `kit/print.html`

```
SHAPE 동아리 [모집 포스터] 를 만들어 줘.

크기: [A4 세로]
알려야 할 것:
- [2026년 봄학기 신입 부원 모집]
- [모집 기간 3월 2일 – 13일]
- [설명회 3월 4일 오후 7시, 301동 109호]
- [지원 링크 QR 자리]
붙일 곳: [학교 게시판. 지나가며 3초 안에 읽혀야 함]

만드는 방법:
- 함께 준 kit/print.html 을 복사해서 고쳐. 새 CSS 를 짓지 마.
- 멀리서 읽히는 큰 글자 하나로 시작하고, 나머지는 작게. 정보를 고르게
  펼치지 말고 크기 차이를 크게 둬.
- 배경은 흰색 + 옅은 모눈. 색은 파랑 하나만.
- 가장자리 10mm 안에는 글자를 두지 마 (자를 때 잘립니다).
- 본문 글자는 ink-600 보다 옅게 하지 마 (종이에서 사라집니다).
- print-color-adjust: exact 를 유지해. 안 그러면 배경이 안 찍혀.
```

## 뽑는 법

인쇄 → PDF 로 저장 → **용지 A4 세로, 여백 없음, 배경 그래픽 켜기**.
