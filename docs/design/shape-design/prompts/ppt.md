# 발표자료를 만들 때 쓰는 프롬프트

## 먼저 — 파워포인트로 고칠 것이라면

만들어 둔 **`SHAPE 발표자료 템플릿.pptx`** 가 사이트의 바로가기 → SHAPE 자료에
있습니다. 구글 슬라이드로 쓸 것이라면 같은 자리의 `(구글 슬라이드)` 판을 받으세요.
장을 복사해 글자만 바꾸는 편이 빠르고, 발표 중에 고치기도 쉽습니다.
아래 프롬프트는 **HTML 한 장으로 받아 PDF 로 뽑을 때** 쓰세요.

## 쓰는 법

Claude 나 Codex 에 이 폴더(또는 아래 세 파일)를 주고, 아래 문장을 복사해
`[ ]` 안만 바꿔 보내세요.

주는 파일: `AGENTS.md`, `kit/shape-kit.css`, `kit/slide.html`

## 복사해 쓰는 문장

```
SHAPE 동아리 발표자료를 만들어 줘.

주제: [신입 부원 모집 설명회]
듣는 사람: [로봇에 관심 있는 신입생, 전공 무관]
분량: [8장 안팎]
꼭 들어갈 내용:
- [우리가 무엇을 하는 사람들인지]
- [한 학기 일정]
- [동아리방과 장비]
- [지원 방법과 마감일]

만드는 방법:
- 함께 준 kit/slide.html 을 복사해서 장을 늘리거나 지우는 방식으로 만들어.
  새 CSS 를 짓지 말고 그 파일에 이미 있는 장 종류(표지·목차·글머리·두 단
  비교·숫자·표·마무리)를 골라 써.
- 색과 글자는 shape-kit.css 의 토큰만 써. 새 색을 만들지 마.
- 한 장에 메시지 하나. 글머리는 다섯 줄을 넘기지 마.
- 말투는 담담한 존댓말. 과장하지 말고 실제로 무엇을 하는지 적어.
- 다 만들면 파일 하나(.html)로 줘. 인쇄 → PDF 로 뽑을 수 있어야 해.
```

## 결과를 PDF 로

브라우저에서 열고 인쇄 → 대상 "PDF 로 저장" → **용지 가로, 여백 없음,
배경 그래픽 켜기**.

## 자주 나오는 잘못

- 장마다 다른 배경색을 칠함 → 흰 바탕이 기본이고, 어두운 장은 표지·마무리 정도
- 글머리를 여덟 줄씩 넣음 → 다섯 줄을 넘으면 장을 나눕니다
- 본문을 18px 로 줄여 다 밀어 넣음 → 24pt 아래로 내리지 않습니다
- 이모지로 아이콘을 대신함 → 쓰지 않습니다
