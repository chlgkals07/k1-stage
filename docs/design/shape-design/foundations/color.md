# 색

## 원칙

SHAPE 의 화면은 **흰 종이**입니다. 색은 위에 얹는 것이지 바탕을 칠하는 것이
아닙니다. 한 화면에서 색이 하는 일은 셋뿐입니다 — 강조(파랑), 무게(남색),
상태 알림(빨강·노랑·초록). 그 밖의 모든 것은 회색 사다리로 처리합니다.

## 파랑 — 강조는 이것 하나뿐

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sh-color-brand-blue` | `#2855f3` | 기본 버튼 배경, 링크, eyebrow 라벨, 강조 숫자 |
| `--sh-color-brand-blue-press` | `#1d4eb5` | 밝은 바탕 위 강한 파란 글자, 눌린 상태 |
| `--sh-color-brand-blue-label` | `#1b4bc4` | 파란 배지 안의 글자 |
| `--sh-color-brand-sky` | `#90afff` | 어두운 바탕 위 보조 글자 |

한 화면에 파란 버튼은 하나입니다. 둘째부터는 `.secondary`(흰 바탕 + 회색 테두리)
로 내립니다. 파랑을 넓은 면에 칠하는 것은 카드 한 장 정도까지입니다.

## 남색 — 무게가 필요할 때만

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sh-color-brand-navy` | `#0c245e` | 푸터, 마무리 슬라이드처럼 통째로 어두운 면 |
| `--sh-color-brand-navy-deep` | `#142354` | 활성 내비 글자 |
| `--sh-color-brand-navy-mid` | `#163c91` | 짙은 카드 |
| `--sh-color-brand-navy-solid` | `#243e78` | 선택된 토글·칩 |

## 회색 사다리

글자는 `ink`, 테두리는 `line`, 면은 `surface`. **이 셋을 섞어 쓰지 마세요** —
테두리에 `ink-400` 을 쓰면 선이 너무 진해 화면이 갑갑해집니다.

```
글자   ink-900 #111111  제목·본문 기본
       ink-700 #39404d  부제
       ink-500 #69717f  본문 보조, 설명
       ink-400 #8a9099  시각·메타 정보
       ink-300 #9aa4b6  안내문(placeholder). 본문에 쓰지 마세요
테두리 line-strong #cbd3e2  눌리는 것(버튼)
       line-base   #d6dce6  입력칸
       line-soft   #e2e6ee  카드
       line-faint  #eef0f4  구획 나누기
면     surface-page        #ffffff
       surface-subtle      #f7f8fb  안내 상자, 댓글
       surface-sunken      #f4f6fa  접히는 영역
       surface-blue        #f4f7ff  hover
       surface-blue-strong #e8efff  선택·승인
       surface-blue-page   #f0f5ff  큰 파란 구획
```

## 상태 색은 반드시 짝으로

글자색만, 또는 배경색만 쓰지 마세요. 배지·안내 상자에서 늘 함께 씁니다.

| 상태 | 글자 | 배경 | 뜻 |
|---|---|---|---|
| info | `#1b4bc4` | `#e7edff` | 승인됨, 예정 |
| success | `#1d6b40` | `#e7f6ed` | 사용 중, 확정 |
| warn | `#7a5405` | `#fdf1d8` | 임시 저장, 조율 중 |
| danger | `#b62446` | `#fdf3f5` | 반려, 충돌, 되돌릴 수 없는 일 |
| staff | `#93341f` | `#ffe9df` | 운영진에게만 보이는 것 |

`danger` 만 테두리(`#f0d2d9`)와 옅은 글자(`#8a3a4e`)가 따로 있습니다. 경고
상자처럼 배경 위에 긴 글을 얹을 때 `#b62446` 은 너무 강해서입니다.

## 대비

본문 글자는 흰 바탕에서 `ink-500`(#69717f, 대비 5.0:1) 아래로 내리지 마세요.
`ink-400` 은 12px 이하 메타 정보에만, `ink-300` 은 placeholder 에만 씁니다.
파란 배경(#2855f3) 위 흰 글자는 5.4:1 로 괜찮지만, 파란 배경 위에 회색 글자를
얹지는 마세요.

## 인쇄할 때

종이 위의 `#2855f3` 은 화면보다 어둡고 탁합니다. 그래도 그대로 씁니다 —
인쇄용으로 색을 따로 만들면 두 벌을 관리하게 됩니다. 대신 **인쇄물의 본문은
`ink-600` 아래로 내리지 마세요.** 옅은 회색은 종이에서 사실상 사라집니다.
배경색을 쓸 때는 `print-color-adjust: exact` 를 걸어야 찍힙니다.
