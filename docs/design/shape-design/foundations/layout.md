# 배치

## 폭과 여백

```
내용 최대 폭   1680px   (--sh-layout-content-max)
긴 글 최대 폭   760px   (--sh-layout-reading-max) — 한 줄이 이보다 길면 못 읽습니다
좌우 여백      max(7vw, calc((100vw - 1680px) / 2))
모바일 여백     20px
```

## 여백 사다리

2·4 배수 위주입니다. 자리마다 쓰는 폭이 대체로 정해져 있습니다.

```
좁은 UI 안쪽 (버튼·칩·배지)   6 ~ 14px
카드 안쪽                    18 ~ 30px
요소 사이                    12 ~ 24px
구획 사이                    56 ~ 120px
```

## 격자

카드 목록은 `repeat(auto-fill, minmax(280px, 1fr))` 이 기본입니다. 열 수를
직접 세지 마세요 — 화면 폭이 바뀌면 알아서 줄어야 합니다.

가로로 긴 것(표, 달력, 카드 줄)은 좁은 화면에서 **단을 줄이거나 가로 스크롤
상자로 바뀌어야** 합니다. `shape-kit.css` 의 `.sh-table-scroll` 과 `.sh-track`
이 그 두 가지입니다. 페이지 본문 자체가 가로로 스크롤되면 안 됩니다.

## 화면 폭 분기

전부 `max-width` 기준입니다. 데스크톱 규칙을 먼저 쓰고 좁은 쪽에서 덮습니다.

| 폭 | 여기서 하는 일 |
|---|---|
| 1400px | 아주 넓은 화면의 상한 조정 |
| 1100px | 세 단 → 두 단 |
| **900px** | 데스크톱 내비를 감추고 햄버거로 바꿉니다 |
| **680px** | **가장 중요한 분기.** 여러 단을 한 단으로 접습니다 |
| 620px | 표·달력을 스크롤 상자로 |
| 430px | 작은 휴대전화. 여백을 더 줄입니다 |

## 화면 높이 — `svh` 와 `dvh`

한 화면이 한 장인 구조(홈처럼)에서는 **고정 픽셀로 여백을 쌓지 마세요.**
사파리에서 첫 화면이 잘립니다.

- `svh` — 주소 표시줄이 나와 있는 **가장 좁은** 상태. 무엇이 반드시 보여야
  할 때 이것을 씁니다.
- `dvh` — 지금 보이는 높이. 스크롤에 따라 값이 바뀌므로 배경에만 씁니다.

## 손가락

누를 것은 최소 44px 입니다. 좁은 화면에서 버튼·칩의 높이를 확인하세요.
`shape-kit.css` 가 680px 아래에서 `min-height` 를 걸어 둡니다.

## 만들고 나서 스스로 볼 것

1. 360px 폭에서 가로로 넘치는 곳이 있는가
2. 표·격자가 좁은 화면에서 단을 줄이거나 스크롤 상자로 바뀌는가
3. 누를 것이 44px 이상인가
4. 한 화면이 한 장인 구조라면, 한 장이 화면 높이를 넘지 않는가
