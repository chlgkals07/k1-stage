# 글자

## 글꼴은 Pretendard 한 벌

`Pretendard Variable`(45–920) 만 씁니다. 세리프도, 모노도, 영문 전용 글꼴도
들이지 않습니다. 한 벌로 영문·한글·숫자를 모두 처리하는 것이 SHAPE 화면이
정돈돼 보이는 가장 큰 이유입니다.

```css
font-family: pretendard, "Pretendard Variable", Pretendard,
             "Apple SD Gothic Neo", "Noto Sans KR", Arial, sans-serif;
```

**구글 폰트에는 Pretendard 가 없습니다.** 그래서 구글 슬라이드·구글 문서처럼
구글 폰트에서만 고를 수 있는 곳에서는 쓸 수 없고, 그런 자리에서는 **Noto Sans KR**
로 대체합니다(위 대체 목록의 그 글꼴입니다). 파일을 올려서 쓸 수 있는 곳
— 파워포인트·키노트·인쇄물 — 에서는 Pretendard 를 씁니다. 글꼴 묶음은 사이트의
바로가기 → SHAPE 자료에 있습니다.

**사이트가 글꼴 파일을 직접 실어 보냅니다.** 사람 컴퓨터에 Pretendard 가
깔려 있기를 기대하면 리눅스·윈도에서 전혀 다른 글꼴로 그려지고, 여유가 십몇
픽셀뿐이던 칸이 그대로 무너집니다. 새 페이지를 만들 때도 대체 글꼴 목록을
끝까지 적어 두세요.

## 크기

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `hero` | `clamp(58px, 7vw, 108px)` | 첫 화면 큰 글자 |
| `display` | `clamp(44px, 4.5vw, 74px)` | 구획 제목 |
| `heading` | 32px | 페이지 안 큰 제목 |
| `title-lg` / `title` | 24 / 22px | 카드 제목, 대화상자 제목 |
| `title-sm` | 19px | 작은 제목 |
| `lead` | 17px | 소개 문단 |
| `body-lg` / `body` | 15 / 14px | 본문 |
| `body-sm` | 13px | **화면에서 가장 많이 쓰는 크기.** 목록, 라벨, 설명 |
| `small` | 12px | 메타 정보, 시각 |
| `caption` / `micro` | 11 / 10px | 배지 안 글자. 이보다 작게 쓰지 마세요 |

발표자료는 이 사다리를 쓰지 않습니다. 슬라이드는 본문 24pt, 제목 46pt,
표지 76pt 부터입니다(`kit/slide.html`).

## 굵기

- **900** — 제목 전부, 숫자 강조, eyebrow 라벨
- **800** — UI 기본. 버튼, 라벨, 표 머리, 배지
- **700** — 본문 안의 강조
- **400** — 긴 글의 본문에만

SHAPE 화면은 전반적으로 굵습니다. 400 을 기본으로 쓰면 다른 사이트처럼 보입니다.

## 자간 — 큰 글자일수록 좁게

한글은 큰 글자에서 자간을 좁혀야 단단해 보입니다. 이것이 SHAPE 제목의 인상을
만드는 핵심이라 빠뜨리면 티가 납니다.

```
hero     -.08em      display  -.07em
title    -.05em      card     -.04em
본문      0           eyebrow  +.14em (대문자 영문 라벨만)
```

## 줄 간격

```
tight  1.12   display 이상
snug   1.25   제목
normal 1.6    본문 기본
loose  1.75   긴 소개 문단
```

## 한글 규칙

- **`word-break: keep-all`** — 단어 중간에서 끊지 않습니다. `shape-kit.css` 가
  `p, li, dd, blockquote, figcaption` 에 이미 걸어 둡니다. 새 요소를 만들면
  직접 걸어 주세요.
- **줄바꿈은 의미 단위로.** 제목을 두 줄로 만들 때 `<br>` 을 넣는 자리는
  숨을 쉬는 자리여야 합니다. "사람을 위한<br>로봇을 만듭니다" 는 좋고,
  "사람을 위한 로봇을<br>만듭니다" 는 어색합니다.
- **숫자는 `font-variant-numeric: tabular-nums`.** 표와 통계에서 자릿수가
  흔들리지 않습니다.
- 영문 라벨은 대문자로 짧게만. 문장을 대문자로 쓰지 마세요.

## 하지 말 것

- 제목에 자간을 0 으로 두기 (헐거워 보입니다)
- 본문에 900 굵기 쓰기
- 12px 아래 크기로 본문 쓰기
- 글꼴 두 벌 섞기
