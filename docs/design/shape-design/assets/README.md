# 자산

## 심볼

`logo/shape-symbol.svg` — SHAPE 심볼. 벡터이므로 크기를 마음대로 바꿔도
됩니다. `logo/shape-symbol.png` 는 SVG 를 쓸 수 없는 곳(구형 슬라이드 도구,
일부 인쇄 업체)에 씁니다.

### 쓰는 규칙

- **어두운 바탕에서는** `filter: brightness(0) invert(1)` 로 흰색으로 뒤집어
  씁니다. 흰색 판본을 따로 만들지 마세요.
- 심볼 주위에는 심볼 높이의 **절반만큼** 빈 자리를 둡니다.
- 심볼을 늘이거나 기울이지 말고, 색을 바꾸지 마세요(흰색 반전은 예외).
- 심볼과 글자 "SHAPE" 를 나란히 둘 때 간격은 심볼 높이의 0.25배입니다.

### 글자 상표

"SHAPE" 는 Pretendard 900 에 자간 `-.03em` 으로 씁니다. 별도의 로고 글꼴이
없으므로, 어디서든 이렇게 쓰면 같은 모양이 나옵니다.

## 글꼴

Pretendard Variable 1.3.9. 파일은 이 폴더에 두지 않고 사이트 저장소에 있습니다.

```
shape_web/frontend/public/fonts/pretendard-1.3.9/
```

라이선스는 SIL Open Font License 1.1 입니다(같은 폴더의 `OFL.txt`). 자유롭게
쓸 수 있지만 글꼴 파일 자체를 팔 수는 없습니다.

사이트는 이 글꼴을 **92개 조각으로 나눠** 실어 보냅니다. 한 페이지가 실제로
쓰는 글자가 든 조각만 내려받게 하기 위해서입니다. 발표자료나 포스터를 만들 때는
그럴 필요가 없으므로, 컴퓨터에 깔린 Pretendard 를 쓰거나 조각 하나를
`@font-face` 로 불러 쓰면 됩니다(`kit/preview.html` 이 그렇게 합니다).
