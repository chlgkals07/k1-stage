# SHAPE 디자인 — 먼저 읽는 파일

당신은 서울대학교 로봇 동아리 **SHAPE** 를 위한 무언가를 만들려 합니다.
이 폴더는 그 결과물이 www.snu-shape.com 과 같은 얼굴을 갖게 하는 자료입니다.
값은 전부 실제 사이트에서 뽑은 것이라, 여기 적힌 대로 하면 사이트와 어긋나지
않습니다.

## 무엇을 만드느냐에 따라 이만큼만 읽으면 됩니다

| 만들 것 | 읽을 것 |
|---|---|
| 웹 화면·컴포넌트 | `kit/shape-kit.css` + `foundations/layout.md` + `components/index.md` |
| 움직이는 웹 (등장·회전·3D) | 위에 더해 `foundations/motion.md` + `kit/motion.js` |
| 발표자료 — 화면·PDF | `kit/slide.html` 를 복사해 고치세요. 그 파일 안에 규칙이 주석으로 있습니다 |
| 발표자료 — 진짜 파워포인트 | 사이트의 **바로가기 → SHAPE 자료** 에서 `SHAPE 발표자료 템플릿.pptx` 를 받아 장을 복사해 쓰세요. 코드로 다시 만들려면 `scripts/build-pptx.py` |
| 발표자료 — 구글 슬라이드 | 같은 자리의 `(구글 슬라이드)` 판을 받아 드라이브에서 여세요. **Pretendard 는 구글 폰트에 없어서** 그 판만 Noto Sans KR 로 짜여 있습니다 |
| 포스터·전단·명함 | `kit/print.html` 를 복사해 고치세요 |
| 색·글자만 필요 | `tokens/tokens.css` (또는 `tokens/tokens.json`) |
| 왜 이런 값인지 알아야 할 때 | `foundations/color.md`, `foundations/typography.md` |

사람이 파워포인트로 직접 고쳐야 하는 자료라면 HTML 이 아니라 **.pptx 템플릿**을
주세요. 29장의 예시(표지·차례·섹션·기본 여섯 장·숫자·표·일정·사진·인용·로드맵·
마무리·부록)와 SHAPE 색이 들어간 테마, 웹의 '나타나기'를 옮긴 등장 애니메이션이
들어 있습니다.

`kit/shape-kit.css` 는 **한 파일로 완결**됩니다. HTML 에 `<link>` 하거나 통째로
`<style>` 안에 넣으면 그대로 동작합니다. 다른 CSS 프레임워크가 필요 없습니다.

## SHAPE 는 이렇게 생겼습니다 — 한 문단

**흰 종이 위의 파랑**입니다. 배경은 거의 언제나 흰색이고, 아주 옅은 남색 모눈이
깔릴 때가 있습니다. 강조는 오직 파랑(`#2855f3`) 하나로 하고, 큰 면을 채워야 할
때만 남색(`#0c245e`)을 씁니다. 글자는 Pretendard 한 벌이며, 제목은 굵고(900)
자간을 눈에 띄게 좁혀(-0.05em 안팎) 단단하게 보입니다. 모서리는 넉넉히 둥글고
(카드 18px), 버튼·태그·내비는 예외 없이 알약 모양입니다. 그림자는 검정이 아니라
파란 기가 도는 남색이고, 아주 넓고 옅게 깝니다. 움직임은 조용합니다 — 아래에서
살짝 올라오며 나타나고, 포인터를 따라 조금 기울고, 라벨이 축을 돌아 넘어갑니다.

## 반드시 지킬 것

1. **색을 새로 지어내지 마세요.** `tokens/tokens.json` 에 있는 것만 씁니다.
   회색이 필요하면 `ink-*` 와 `line-*` 중에서 고릅니다.
2. **글꼴은 Pretendard 하나입니다.** 세리프·모노·구글 폰트를 새로 들이지 마세요.
   못 쓰는 환경이면 `-apple-system, "Noto Sans KR", sans-serif` 로 대체합니다.
   구글 슬라이드·구글 문서처럼 **구글 폰트만 쓸 수 있는 곳에서는 Noto Sans KR**
   입니다. Pretendard 는 구글 폰트에 없습니다.
3. **버튼·태그·칩은 알약(`border-radius: 999px`)입니다.** 각진 버튼은 SHAPE 가
   아닙니다.
4. **그림자에 검정을 쓰지 마세요.** `rgba(0,0,0,…)` 대신 `--sh-shadow-*` 를 씁니다.
5. **한글 문단에는 `word-break: keep-all`** 을 겁니다. 단어 중간에서 끊기면
   읽기 나쁩니다. `shape-kit.css` 가 이미 걸어 둡니다.
6. **모바일을 함께 만듭니다.** 360~430px 폭에서 넘치거나 잘리는 곳이 없어야
   하고, 누를 것은 최소 44px 입니다. 데스크톱만 만든 결과물은 미완성입니다.
7. **움직임은 반드시 끌 수 있어야 합니다.** `prefers-reduced-motion: reduce`
   블록을 빼먹지 마세요. `shape-kit.css` 에 이미 있습니다.
8. **한 화면에 강조는 하나.** 파란 버튼이 둘 이상 나란히 있으면 하나는
   `.secondary` 로 내립니다.

## 하지 말 것

- 그라데이션으로 배경 전체를 칠하기 (SHAPE 의 배경은 흰색입니다)
- 보라·초록·분홍을 강조색으로 쓰기 (상태 표시 말고는 파랑뿐입니다)
- 이모지를 아이콘 대신 쓰기 (선 아이콘을 쓰거나 글자로 씁니다)
- 그림자를 진하게 깔기 (SHAPE 의 그림자는 있는 듯 없는 듯합니다)
- 본문을 12px 아래로 내리기, 슬라이드 본문을 24px 아래로 내리기
- 문장 끝마다 느낌표를 붙이기 (말투는 담담한 존댓말입니다)

## 말투

담담한 존댓말입니다. "~합니다", "~해 주세요". 과장하지 않고, 광고 문구처럼
쓰지 않습니다. 동아리 소개에서도 "최고", "혁신", "열정" 같은 말 대신 실제로
무엇을 하는지 적습니다. 영문 라벨(EYEBROW)은 대문자로 짧게만 씁니다.

- 동아리방: 서울대학교 301동 공과대학 제1공학관 109호

## 이 폴더를 고칠 때

`tokens/tokens.json` 과 `kit/_kit-source.css` 만 손으로 고칩니다.
`tokens/tokens.css`, `kit/shape-kit.css`, `kit/token-names.js` 는 생성물이므로
고쳐도 다음 빌드에 지워집니다. 고친 뒤에는 반드시:

```
node design-system/scripts/build-tokens.mjs   # 생성물 다시 만들기
node design-system/scripts/drift-check.mjs    # 사이트가 토큰에서 벗어났는지 검사
```
