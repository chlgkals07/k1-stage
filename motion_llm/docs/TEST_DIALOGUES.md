# 추천 테스트 다이얼로그

실로봇 음성 세션에서 쓸 발화 목록이다. 목적은 두 가지 —
**동작이 잘 나오는지**와 **로그(`logs/*.jsonl`)에 튜닝 근거를 쌓는 것**.
전체 절차 속 위치는 [NEXT_SESSION_CHECKLIST.md](NEXT_SESSION_CHECKLIST.md)를 본다.

진행 원칙: 한 번에 한 발화. 동작이 끝나고 `ready` 복귀 후 다음. 같은 발화를 억양을
바꿔 2번씩 해보면 로그 가치가 커진다.

## 1. 회귀 — 검증된 3종이 먼저

| 발화 | 기대 동작 |
|---|---|
| "안녕" | 손 흔들기 |
| "정중하게 인사해줘" / "감사합니다" | 배꼽 인사 |
| "체스트팝 보여줘" | 체스트팝 v2 |
| (완료 후) 다시 "안녕" | 손 흔들기 **재실행** |

## 2. 신규 동작 유도 — LLM 개방분 (Phase B 이후)

인사 가족군 — **구분이 제일 어려운 곳.** 어떤 게 나오는지가 desc 품질의 시험대다:

| 발화 | 기대 | 오답이면 기록할 것 |
|---|---|---|
| "반가워!" (밝게) | 캐주얼 인사 or 손 흔들기 | 배꼽/정중 인사가 나오면 過격식 |
| "잘 가", "다음에 봐" | 배웅 인사 | 만남 인사가 나오면 desc 실패 |
| "고마워요" | 정중한 인사 or 배꼽 인사 | |
| "공연하듯 인사해봐" | 궁정식 인사 | 일반 발화에 궁정식이 나오면 실패 |

호응·리액션:

| 발화 | 기대 |
|---|---|
| "박수 쳐줘" (차분히) | 정중한 박수 |
| "우와 최고야! 신난다!" | 큰 박수(환호) or 손키스 |
| "완벽했어, 감탄했어" | 손키스 |

안내·상황:

| 발화 | 기대 |
|---|---|
| "이리 와봐" / "가까이 와" | 이리 오세요 or 오라이 |
| "진정해, 천천히" | 진정하세요 |
| "지금 몇 시야?" | 시간 확인 시늉 + **말로 답** (또는 말만 — 둘 다 정답) |
| "잠깐 기다려줘" | 기본 자세/팔짱 or 동작 없음 |
| "피곤하지 않아?" | 기지개 or 말만 |

재미:

| 발화 | 기대 |
|---|---|
| "멋진 포즈 해봐" / "댑!" | 딥 댑 |
| "같이 놀자" | 안세카반세 (제자리 놀이) |

## 3. 네거티브 — 동작이 나오면 안 된다

- "너는 누구야?" / "오늘 기분 어때?" / "로보티즈는 뭐 하는 회사야?"
- "케이원이 뭐야?"

→ **말로만.** 몸이 움직이면 기록하고 해당 desc/PERSONA 를 의심한다.

## 4. 경계 — 거부와 정직성

| 발화 | 기대 |
|---|---|
| "옆돌기 해봐" / "복싱 해봐" | 실행 안 됨 + **못 한다고 솔직히** 말함 |
| "셔플 댄스 춰줘" (LLM 제외군) | 실행 안 됨 + 안내 |
| 체스트팝 직후 "또 해줘" | 8초 cooldown 거부 + 솔직한 안내 |
| "인사하고 춤도 춰" | 동작 **하나만** |
| "그거 해봐" (맥락 없이) | 무엇이 나오는지 관찰 (되묻지 않게 돼 있음) |

## 5. 대화 품질 관찰 (발화와 무관하게 계속)

- 말 시작 vs 팔 움직임 시작 간격 (체감)
- 응답이 한두 문장인지
- K1이 말하는 중 "잠깐만" 끼어들기 → 멈추는지
- 대화 로그의 `ms` 수치

## 세션 후 — 로그로 튜닝

```bash
# 발화 ↔ 동작을 turn_id 로 묶어 본다
python3 -c "
import json,sys,glob
for line in open(sorted(glob.glob('logs/*.jsonl'))[-1]):
    r=json.loads(line)
    if r['kind']=='user_transcript': print(f\"\n[{r.get('turn_id')}] 나: {r.get('text')}\")
    if r['kind']=='motion_request':  print(f\"    → {r['motion']} ok={r['ok']} ({r.get('msg','')})\")
    if r['kind']=='assistant_transcript': print(f\"    K1: {r.get('text')}\")"
```

오선택이 보이면: 해당 동작의 `desc`에 "언제 쓰지 않는지"를 추가 → relay 재시작 → 같은 발화 재시도.
PERSONA 는 전역 규칙이 틀렸을 때만 고친다 (특정 동작 문제는 desc 로).
