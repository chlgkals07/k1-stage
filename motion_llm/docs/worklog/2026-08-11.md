## 무선/SSH 상태

처음에는 PC Wi-Fi가 disconnected였고, `192.168.50.1` route가 유선 LAN으로 잘못 잡혀 있었다.

나중에 route는 정상으로 바뀌었다.

```text
192.168.50.1 dev wlp128s20f3 src 192.168.50.77
```

간단한 SSH check는 성공했다.

```bash
ssh -o BatchMode=yes -o ConnectTimeout=5 root@192.168.50.1 true
```

이후 robot 내부 상태를 한 번에 확인하는 긴 SSH 명령은 응답이 오래 걸려 중단했다. 다음에는 단순 SSH로 들어간 뒤 단계별로 확인하는 것이 낫다.
